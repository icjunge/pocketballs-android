# 球屿 · Pocket Balls 0.1.1

面向三星 Galaxy Z Fold7 的小球测试应用，Android 8.0+，target SDK 35。小球场景可完全离线运行，检查和下载更新需要网络。

- 原生姿态/重力驱动物理：哪边低往哪边滚，支持横竖屏坐标转换。优先使用融合陀螺仪的游戏旋转矢量，后台线程请求 120 Hz 采样，画面每帧使用最新值；无额外场景重力平滑。
- 外屏、展开内屏、旋转和分屏按窗口尺寸布局；普通折叠切换保留球体数量、大小和运动状态。
- 彩色足球/网球/篮球/排球，网球较小，1–32 个球；盒内深度、阴影、景深及随倾斜变化的视差。
- 默认全屏，右上角折叠毛玻璃菜单；无需登录或 Shizuku。
- 物理按经过时间推进，绘制上限 60 Hz；内屏降低初始像素密度，持续低帧率优先关闭景深后处理，保留盒底、阴影和视差。
- 应用内检查更新、下载进度与安装按钮；启动时最多每 6 小时自动检查一次，有新版仅显示菜单角标。下载和系统安装确认都由用户操作。
- 原生 Android 生命周期与传感器 + 内置 WebGL 场景。此版用于确认效果，尚未在实体 Fold7 验收。

## 构建

Java 17 + Python 3：

```sh
python3 tools/restore-android-sdk.py /absolute/path/pocket-sdk
POCKETBALLS_ANDROID_SDK=/absolute/path/pocket-sdk bash tools/build-android.sh "$PWD"
```

脚本校验官方 SDK 下载的大小和 SHA-256，编译 Java/DEX、打包并校验 ZIP 对齐。

GitHub Actions 生成 `PocketBalls-build-input`，其中 APK **尚未签名，不能直接安装**。最终安装包在受控环境使用保留的开发密钥签名；签名密钥不提交到此仓库。后续版本使用同一密钥才能覆盖安装。

## 更新发布

已签名安装包放在 `releases/v<版本>/PocketBalls-<版本>-Fold7.apk`，`updates/latest.json` 指向最新版本并包含版本号、包名、最低系统版本、字节数及 SHA-256。先完成构建、签名和验证，再将安装包与更新清单在同一个提交中发布。`Verify published update` 工作流验证本地文件与公网下载地址。

应用仅接受此仓库的 HTTPS 更新地址，并在安装前再次核对文件大小、SHA-256、包名、版本和与当前应用相同的签名。安装包保存在应用私有目录，通过只读 ContentProvider 授权系统安装器读取。

0.1.0 需要手动覆盖安装 0.1.1 一次，以后可在右上角菜单中检查更新。首次应用内安装时，系统会要求允许球屿安装未知应用；返回后继续系统安装确认。无需卸载旧版。

## 验证范围

主机测试覆盖 24 个重力映射场景、266 个旋转矢量检查、更新策略和 15/30/60/120/144 Hz 下的物理时序。浏览器测试覆盖更新 UI、暂停与恢复、折叠窗口尺寸、分屏和保存状态。Android 云构建校验编译、打包和权限；测试不等于 Fold7 真机传感器延迟、实际帧率或系统安装验收。

测试目标：四边倾斜、保持倾斜、外屏→内屏→外屏、横屏、分屏、后台返回、不同球与数量切换。手机真实帧率、One UI 折叠生命周期和安装结果需实机验证。
